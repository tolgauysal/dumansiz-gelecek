Android Uygulaması

Dumansız Gelecek web uygulamasını Android telefonunuzda kolayca kullanabilirsiniz. APK dosyasını indirerek uygulamayı yükleyebilirsiniz.

📋 Özellikler

  • Tam ekran WebView uygulaması
  • İnternet bağlantısı ile çalışır
  • Portrait modunda optimize edildi
  • Tüm Android cihazlarla uyumlu
  • Hafif ve hızlı

📦 APK Dosyası Bilgisi:

• Sürüm: 1.0.0

• Min API: Android 5.0 (API 21)

• Target API: Android 12 (API 31)

• Boyut: ~50 MB

📥 APK İndir 👨‍💻 GitHub

⚠️ Kurulum Talimatı:

1. APK dosyasını indirin

2. Telefonda bilinmeyen kaynaktan yüklemeye izin verin

3. APK dosyasını açın ve kurun

4. "Dumansız Gelecek" uygulamasını başlatın
